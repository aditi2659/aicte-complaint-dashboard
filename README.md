
# AICTE Complaint Monitoring Dashboard

An integrated dashboard prototype for monitoring and tracking institution-related complaint cases across AICTE Bureaus and Cells.

## Project Modules

- `frontend/` — React user interface and dashboard
- `backend/` — Node.js and Express APIs, authentication, and integration
- `features/complaint-matching/` — Cross-Bureau complaint intelligence
- `features/early-warning/` — Case deadline monitoring and alerts
- `features/complaint-summarization/` — AI-assisted complaint summaries
- `database/` — Database schema, migrations, and sample data
- `docs/` — Project workflow and documentation
