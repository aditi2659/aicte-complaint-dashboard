# Prototype workflow

1. An authorized user signs in (authentication is a planned integration; not implemented in this starter).
2. User views dashboard summary.
3. User registers or opens a complaint.
4. The system compares complaints across Bureaus/Cells.
5. Potentially related cases are shown with scores and reasons.
6. An authorized official reviews suggestions and decides whether to link cases.
7. Case actions and status updates are recorded.
8. Analytics and deadline alerts summarize workload.

All current example records are fictional. This starter is not connected to AICTE production systems.
