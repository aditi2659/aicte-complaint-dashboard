# Team contribution guide

1. Agree on a task before editing shared files.
2. Create a branch, e.g. `git switch -c feature/your-module`.
3. Make and test your changes.
4. Commit with a descriptive message.
5. Push the branch: `git push -u origin feature/your-module`.
6. Open a Pull Request and ask a teammate to review it.
7. Merge to `main` only after review and integration testing.

Do not commit `.env`, credentials, API keys, or real complaint data.
